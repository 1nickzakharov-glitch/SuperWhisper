## ✨ Возможности

- **⚡️ Гибридная архитектура (Облако + Офлайн)**:
  - **Когда есть интернет**: аудио мгновенно обрабатывается через облачный Whisper (*DeepInfra Large-v3-Turbo*). 2–4 минуты связной речи транскрибируются за **1–2 секунды** без нагрева процессора и нагрузки на аккумулятор Mac.
  - **Когда нет интернета**: приложение автоматически и бесшовно переключается на локальный движок **WhisperKit** (Apple Neural Engine / Metal GPU). Вы можете диктовать текст в самолёте или при нестабильной связи.
- **🌊 Интерфейс Liquid Glass**:
  - Плавающее минималистичное окно в стиле Siri / Jarvis с полупрозрачным матовым стеклом, адаптирующимся к светлым и тёмным окнам.
  - Процедурный 60 FPS эквалайзер с волновым куполом, шахматным чередованием амплитуды линий и бегущими гармониками.
- **⌨️ Мгновенная автовставка (`Cmd+V`)**:
  - Нажали хоткей (`⌥ Space` по умолчанию), надиктовали мысль, нажали снова — распознанный текст автоматически вставляется прямо в активный текстовый курсор (Telegram, браузер, терминал, заметочник, Word, IDE).
  - Исходное содержимое буфера обмена бережно сохраняется и восстанавливается.
- **✍️ Интеллектуальная пунктуация и фильтрация**:
  - Автоматическая расстановка запятых перед союзами (*что, чтобы, если, когда, потому что, то есть, хотя, будто*), вводными словами (*кстати, конечно, наверное, во-первых*) и капитализация предложений.
  - Встроенный фильтр артефактов и галлюцинаций Whisper (*«Продолжение следует...»*, титры, паузы).
- **🔒 Приватность**:
  - Никакой скрытой телеметрии и аналитики. Все настройки и ключи хранятся локально на вашем компьютере в `UserDefaults`.

## 🚀 Быстрый старт

### Требования
- macOS 14.0 (Sonoma) или новее (Sequoia поддерживается).
- Mac на базе Apple Silicon (M1/M2/M3/M4) или Intel.
- Права доступа к **Микрофону** и **Универсальному доступу** (Accessibility) для вставки текста.

### Сборка из исходников

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/1nickzakharov-glitch/SuperWhisper.git
cd SuperWhisper

# 2. Соберите релизную версию
swift build -c release

# 3. Скопируйте бинарник в бандл и подпишите
cp .build/release/SuperWhisper SuperWhisper.app/Contents/MacOS/SuperWhisper
codesign --force --deep --sign - SuperWhisper.app

# 4. Переместите в Программы и запустите
cp -R SuperWhisper.app /Applications/
open /Applications/SuperWhisper.app
```

## 🔑 Настройка облачного распознавания (DeepInfra / OpenAI-совместимые API)

SuperWhisper полностью автономен и работает **бесплатно из коробки** на локальном движке WhisperKit.

Для активации **молниеносного гибридного режима** (1-2 секунды на длинные аудио) вы можете подключить облачный API:
1. Откройте настройки: иконка в строке меню или хоткей `⌥ Space` -> вкладка **«Нейросеть»**.
2. Введите API-ключ в поле *«API Ключ DeepInfra»*.
3. Режим автоматически начнёт использовать облако при наличии соединения.

> 💡 **Где получить ключ?**
> - **[DeepInfra](https://deepinfra.com)** — предоставляет модели `openai/whisper-large-v3-turbo` по ценам порядка ~$0.0003 за минуту (~0.02 руб/мин, $1 хватает на недели непрерывной диктовки).
> - Также поддерживаются любые OpenAI-совместимые сервисы с эндпоинтом `/v1/openai/audio/transcriptions`.
> - Если ключ не указан — приложение работает **100% бесплатно и локально** через WhisperKit.

## 💻 Выбор локальных моделей (WhisperKit)

В настройках во вкладке **«Нейросеть»** вы можете выбрать локальную CoreML-модель для автономной работы:
- **Large-v3-Turbo** (598 МБ) — флагманская точность русского и английского языка, знаков препинания и сложных терминов.
- **Small** (460 МБ) — отличный баланс качества и скорости на базовых конфигурациях Mac.
- **Base** (140 МБ) — быстрая и лёгкая модель.
- **Tiny** (75 МБ) — ультракомпактная модель с минимальным весом.

## 🛠 Управление

- `⌥ Space` (Option + Space) — старт / завершение диктовки (комбинацию можно переназначить в настройках).
- Клик по иконке в Menu Bar — статус, быстрый переход в настройки и выход.
- При наведении курсора на плавающий HUD доступны интерактивные кнопки:
  - ✕ — отменить запись без вставки.
  - ⏸ / ▶ — поставить запись на паузу или продолжить.
  - ✓ — досрочно завершить и вставить текст.
